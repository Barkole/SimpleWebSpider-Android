# SimpleWebSpider-Android Agent

## Purpose
This agent manages the SimpleWebSpider-Android project, an Android web crawler app. It handles modernization, CI/CD, dependency updates, and release management.

## Key Responsibilities
- Maintain project structure and build configurations
- Ensure CI/CD pipelines work correctly
- Handle dependency updates and security patches
- Create releases with APK files
- Follow semantic versioning
- Keep documentation up to date

## Workflows
- On every commit: Build APK, run tests
- On main branch push: Create release if conventional commit
- Weekly: Update dependencies via Dependabot
- Auto-merge successful dependency PRs

## Instructions
- Use conventional commits for versioning
- Keep Android SDK up to date
- Migrate deprecated APIs

## Tools
- Gradle for builds
- GitHub Actions for CI/CD
- Dependabot for dependencies
- Semantic-release for versioning
